Интернет-магазин - это веб-платформа для продажи товаров онлайн, разработанная на Django.

**Установка и развёртывание**

### Вариант 1. Быстрый запуск в Docker (Рекомендуемый)
Для запуска проекта необходим установленный Docker Desktop. Этот способ автоматически развернет бэкенд на Django и промышленную базу данных PostgreSQL.

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com
   cd megano-django
   ```
2. Запустите сборку и старт контейнеров:
   ```bash
   docker-compose up --build
   ```
3. Создайте суперпользователя (администратора) в новом окне терминала:
   ```bash
   docker-compose exec web python diploma-backend/manage.py createsuperuser
   ```
Проект будет доступен по адресу: http://localhost:8000/

---

### Вариант 2. Локальный запуск (Классический)
Для запуска непосредственно на хост-машине с использованием локальной базы данных:

1. Клонируйте репозиторий и перейдите в папку:
   ```bash
   git clone https://github.com
   cd megano-django
   ```
2. Установите зависимости проекта:
   ```bash
   pip install -r requirements.txt
   ```
3. Выполните миграции базы данных:
   ```bash
   python diploma-backend/manage.py migrate
   ```
4. Запустите сервер разработки:
   ```bash
   python diploma-backend/manage.py runserver
   ```

**Основные компоненты**
*Фронтенд*

- главная страница: отображение популярных товаров, акций и новинок;
- каталог товаров: фильтрация, сортировка, пагинация;
- карточка товара: детальное описание, отзывы, форма добавления в корзину;
- корзина: управление товарами, оформление заказа;
- личный кабинет: профиль, история заказов, отзывы.

*Бекенд*

- управление товарами: категории, характеристики, цены;
- система заказов: оформление, оплата, статусы;
- админ-панель: управление контентом, пользователями, заказами;
- авторизация: регистрация, восстановление пароля.

**Роли пользователей**

- администратор: полный доступ к админ-панели;
- покупатель: доступ к личному кабинету, оформлению заказов;
- гость: просмотр каталога, добаление товаров в корзину.

**Функционал**

- фильтрация по категориям и характеристикам;
- сортировка по популярности, цене, новизне
- система отзывов
- сравнение товаров

**Оформление заказа**

- корзина с управлением количеством;
- выбор способа доставки;
- способы оплаты;
- история заказов.

**Личный кабинет**

- управление профилем
- история заказов
- отзывы
- избранное.
